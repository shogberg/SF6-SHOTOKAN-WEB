# Search and home (`/`)

- **Search box** (top of every page): player name, past names, or CFN ID. As-you-type suggestions show name, main character, MR band and number of sets.
- **Home:** latest reviewed sets, players with the most sets, links to the analysis pages, and the snapshot date.
- **Comparing two players:** pick a second player from a profile, or type `shog vs jon`, to open [head to head](head-to-head.md).

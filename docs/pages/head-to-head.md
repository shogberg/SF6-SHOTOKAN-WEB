# Head to head (`/h2h/{a}/{b}`)

All sets between two players, e.g. .shog vs jon.
- **Record:** sets, games and rounds; first and last meeting; streaks.
- **Timeline:** each set as a card (date, score, characters, review level), linking to set detail.
- **How they play each other:** each player's archetype and spectra **in this pairing vs their overall profile**, with the biggest differences called out (e.g. "jon presses after blocking 10.7× a game against shog, 4.8× in general").
- **What decides it:** most common damage sources each way (situation and lens), top starters, punishes, and what changed between their earliest and latest sets.
- **Predictions:** past predictions for this pairing and how they graded.

URL order doesn't matter; the API normalises the pair and returns both perspectives.

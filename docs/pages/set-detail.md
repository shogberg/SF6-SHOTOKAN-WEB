# Set detail (`/sets/{set_key}`)

Replaces the per-review dashboard.
- **Header:** players, characters, format (FT2/FT3), set score, the score after each game, date, context (ranked / casual / local / tournament), MR or league at the time.
- **Prediction** (if one was written before review): predicted winner and score, confidence, path to victory, key factors, and the grade (right/wrong, what it missed). Shown before the results section, as it was written before them.
- **Games:** each game's round score and round winners, and a summary and turning point (Full and Tournament reviews).
- **Players:** each side's archetype and spectra for this set, habits, and how they adapted.
- **Story of the set** (Full / Tournament): top highs and lows, findings by category, game cards.
- **Tournament audit** (Tournament): decision audit and each player's side.
- **Numbers:** damage by situation and lens, hits by kind, KPIs, Drive and super spending, Drive economy, parries.
- **Every hit:** filterable table.

Quick reviews show what they have (numbers, computed reads) and hide the written sections.

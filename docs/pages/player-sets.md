# Player sets (`/players/{id}/sets`)

A table of every set the player is in, newest first.

| Column | |
|---|---|
| Date | |
| Opponent | link to their profile and to head to head |
| Characters | player's / opponent's |
| Result | set score, W/L coloured |
| Games | game scores, e.g. 2-1, 1-2, 2-0 |
| MR / league | both players at the time (raw; effective if adjusted) |
| Archetype | this player's read for the set |
| Review | Quick / Full / Tournament |
| Prediction | ✓ / ✗ when there was one |

Filters: date range, opponent, character, result, review level, ranked/casual/local, MR band. Totals at the top follow the filters: record, sets, games.
